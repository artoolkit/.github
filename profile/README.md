# ARToolKit is now artoolkitX

This is the original GitHub organization for ARToolKit, maintained in order to preserve links to the ARToolKit v5.

ARToolKit today exists in active development under the artoolkitX name. You can find the artoolkitX project, including native, Unity, and web versions here on GitHub at https://github.com/artoolkitx

The original ARToolKit project was initially developed by Hirokazu Kato and Mark Billinghurst in 1999. Since 2003, the project has been continuously managed by Philip Lamb, variously under the former ARToolworks Inc. company, DAQRI, LLC, and since 2018 as an independent open-source project.
